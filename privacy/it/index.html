Informativa sulla privacy di Paste Advanced

Ultimo aggiornamento: 25 marzo 2026

Paste Advanced è una utility desktop locale per Windows sviluppata da Twicode per aiutare gli utenti a eseguire operazioni avanzate di copia di file e cartelle.

Panoramica

Paste Advanced è progettata per funzionare localmente sul dispositivo dell’utente.

Come parte delle sue funzionalità principali, Paste Advanced non richiede un account utente, non richiede un servizio cloud e non invia file personali o contenuti di file ai server di Twicode.

Accesso a file e cartelle

Paste Advanced lavora con file e cartelle selezionati esplicitamente dall’utente.

Per eseguire le operazioni richieste, l’applicazione può accedere, leggere, copiare, creare, rinominare, spostare o eliminare file e cartelle sul dispositivo dell’utente, ma solo nella misura necessaria a eseguire azioni avviate dall’utente stesso.

Poiché l’applicazione elabora file e cartelle selezionati dall’utente, può trattare contenuti che includono informazioni personali. Questa elaborazione avviene localmente sul dispositivo.

Archiviazione locale dei dati

Paste Advanced può memorizzare localmente sul dispositivo dell’utente una quantità limitata di dati applicativi per fornire le funzionalità previste e preservare l’esperienza d’uso.

Questi dati locali possono includere, ad esempio:

  • preferenze dell’utente
  • opzioni selezionate
  • impostazioni delle hotkey
  • impostazioni del comportamento delle finestre
  • dati del journal delle operazioni usati per funzionalità legate all’undo

Questi dati sono archiviati localmente e non vengono trasmessi a Twicode come parte delle funzionalità principali dell’applicazione.

Raccolta e trasmissione dei dati

Paste Advanced non raccoglie dati personali per finalità di analytics, pubblicità o profilazione come parte delle sue funzionalità desktop principali.

Paste Advanced non trasmette file personali o contenuti personali dei file ai server di Twicode come parte delle sue funzionalità principali.

Servizi di terze parti e piattaforme di distribuzione

Paste Advanced non è progettata per inviare dati personali a servizi di terze parti di analytics, advertising o tracking come parte delle sue funzionalità principali.

Tuttavia, se l’applicazione viene distribuita tramite piattaforme di terze parti come Microsoft Store o GitHub, tali piattaforme possono raccogliere determinati dati di piattaforma in base ai propri termini e alle proprie informative sulla privacy. Twicode non controlla le pratiche di trattamento dei dati di tali piattaforme esterne.

Attività di rete

Paste Advanced non richiede una connessione online per le sue funzionalità principali.

Se versioni future dell’applicazione introdurranno funzionalità online opzionali, integrazioni o servizi cloud, questa informativa sulla privacy potrà essere aggiornata di conseguenza.

Modifiche a questa informativa

Twicode può aggiornare questa Informativa sulla privacy di tanto in tanto.

La versione pubblicata sul sito ufficiale di Paste Advanced deve essere considerata la versione corrente.
