Privacy Policy for Paste Advanced

Last updated: March 25, 2026

Paste Advanced is a local Windows desktop utility developed by Twicode to help users perform advanced file and folder copy operations.

Overview

Paste Advanced is designed to operate locally on the user's device.

As part of its core functionality, Paste Advanced does not require a user account, does not require a cloud service, and does not send personal files or file contents to Twicode servers.

File and folder access

Paste Advanced works with files and folders explicitly selected by the user.

To perform requested operations, the application may access, read, copy, create, rename, move, or delete files and folders on the user's device, but only as needed to execute actions initiated by the user.

Because the application processes user-selected files and folders, it may handle content that contains personal information. This processing takes place locally on the device.

Local data storage

Paste Advanced may store limited application data locally on the user's device to provide expected functionality and preserve the user experience.

This local data may include, for example:

  • user preferences
  • selected options
  • hotkey settings
  • window behavior settings
  • operation journal data used for undo-related features

This data is stored locally and is not transmitted to Twicode as part of the application's core functionality.

Data collection and transmission

Paste Advanced does not collect personal data for analytics, advertising, or profiling as part of its core desktop functionality.

Paste Advanced does not transmit personal files or personal file contents to Twicode servers as part of its core functionality.

Third-party services and platform providers

Paste Advanced itself is not designed to send personal data to third-party analytics, advertising, or tracking services as part of its core functionality.

However, if the application is distributed through third-party platforms such as Microsoft Store or GitHub, those platforms may collect certain platform-level data under their own terms and privacy policies. Twicode does not control the data practices of those external platforms.

Network activity

Paste Advanced does not require an online connection for its core functionality.

If future versions of the application introduce optional online features, integrations, or cloud-based services, this Privacy Policy may be updated accordingly.

Changes to this policy

Twicode may update this Privacy Policy from time to time.

The version published at the official Paste Advanced website should be considered the current version.
